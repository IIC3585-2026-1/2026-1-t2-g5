## Demo web (opcional)

```bash
npm install
npm run build:demo
npm run demo
```

Abre la URL que indique `serve` (por defecto http://localhost:5173). El build copia `data/*.json` a `demo/public/data/` y genera `demo/public/query-demo.js`.
